# Contributing

Ontoplexis is developed and maintained by
[Wise Ideas](https://github.com/wise-ideas). Bug reports are welcome on the
[issue tracker](https://github.com/wise-ideas/ontotheke/issues); code
contributions come from within Wise Ideas, so unsolicited pull requests are
generally not accepted.

When reporting a bug, please include the ontology document (or a minimal
excerpt) that triggers it and the exact error output.

The toolchain, workflow, and invariants for working on the code are
documented in the
[development setup guide](https://wise-ideas.github.io/ontotheke/ontoplexis/contrib/setup/).
